## what I'm building

### 💳 CRENIT — rent as a credit engine

> *Millions of renters pay on time every month. None of it builds their credit score.*

**CRENIT fixes that.**

Every rent payment becomes a credit event. On-time means score goes up. Late means accountability. Consistently. This is the kind of infrastructure that should have existed years ago — so I'm building it.

```
the problem   →  renters are invisible to the credit system
the fix       →  every payment is scored, tracked, and reported
the result    →  financial identity, built through rent
```

**Stack:** React · TypeScript · NestJS · PostgreSQL · TypeORM · JWT · RBAC · KYC

**Phase 1 — shipped ✅**

| Feature | Status |
|---|---|
| Auth system (JWT + role-based access) | ✅ done |
| Landlord dashboard — properties, tenants, payments | ✅ done |
| Tenant dashboard — credit score + payment history | ✅ done |
| KYC document verification workflow | ✅ done |
| Auto credit score engine on every payment | ✅ done |
